# 魔方

在浏览器里转三阶魔方。可以自己打乱、计时还原，也可以按层先法一步步看讲解。实物魔方可以逐块涂色，或拍照识别一面的颜色，再自动演示步骤。

配色按常见标准：黄上、白下、绿前、蓝后、红右、橙左。讲解用层先法：先把白色转到下面，再做底十字、底角、中层棱、顶面十字、顶角朝向、顶角位置和顶棱。

## 本地运行

```bash
npm install
npm test
npm run dev
```

电脑打开终端里的本地地址。手机和电脑在同一网络时，用终端里的局域网地址即可在手机上打开。

顶栏可以收起下面的操作面板，魔方会占满剩下的画面。再点一次同一个按钮就能把面板打开。这个选择会记在本机。

## 安卓安装包

网页仍然可以用 Chrome「添加到主屏幕」。另外可以用 Capacitor 打出 APK。

本机需要 JDK 21 和 Android SDK。第一次：

```bash
npm install
npm run android:add
npm run android:apk
```

调试包在 `android/app/build/outputs/apk/debug/`。之后改了页面，再运行 `npm run android:apk` 即可。`android/` 目录是生成出来的，不放进 git。

推送到 `main` 或 `master`、打 `v*` 标签，或者在 GitHub 上手动运行 “Android APK”，Actions 会跑测试、同步网页并上传调试版 APK。这是可以直接装到手机上的调试包。上架用的签名包需要自己的密钥，没有放进这条流水线。

拍照在安装包里会向系统要相机权限。选相册里的照片不依赖这个权限。

## 操作

- 拖色块转动那一层，拖空白处转动视角，双指缩放。
- 顶栏「设置」里可以打开专业模式。默认只能转上面、前面、右面的顺时针和逆时针。专业模式加上下、左、后、中层、转半圈和整个魔方。
- 「打乱」每次从复原开始，只用 U、U'、F、F'、R、R'。这六种转动能到达任意合法状态。
- 语音讲解默认关闭。打开后，教学会朗读当前这一步的说明。
- 字母是面，`'` 是逆时针，`2` 是转 180°。`x` `y` `z` 是整个魔方转动。
- 教学里可以选层先法或 CFOP（十字、F2L 角棱配对、两段 OLL、两段 PLL）。Roux 和 ZZ 目前只有介绍。
- 教学里点「下一步」或「自动播放」。自己拖出和讲解相同的一步时，进度会跟着走。
- 录入时每种颜色应是 9 块，中心颜色互不相同。识别结果可以点一下改色。
